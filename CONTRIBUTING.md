# Contributing

1. Read AGENTS.md and matching .agents/skills/*/SKILL.md.
2. Find the relevant issue in the master tracker #13; propose changes to scope there.
3. Branch from main with feat/, fix/, docs/ or chore/ prefix.
4. Use a pull request and fill .github/pull_request_template.md.
5. Run only relevant project tests plus global safety checks; document missing test coverage.
6. Never log/commit credentials or real personal/payment information.
7. Avoid adding packages or new services without explaining why built-ins are insufficient.
8. Changes affecting payments, tenant isolation or migrations require adverse-case test evidence.
9. Merge only after CI/review and preserve evidence in the issue.

No runnable application package exists yet; bootstrap work is tracked in issue #2.
