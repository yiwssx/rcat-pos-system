## Responsive product media correction (22 Nov 2026)

Owner screenshot after Expressive deployment showed portrait beverage photos cropped at the top/bottom in a narrow desktop browser window. Existing 4:3 `object-cover` was the cause; do not mistake clipping for actual box overflow. Use bounded 4:3 thumbnail frames (max height 11rem), centered `object-contain` with small padding, and a height-clamped contained detail photo. Merchant previews also preserve the full source. Catalog grid uses `repeat(auto-fill,minmax(min(100%,10rem),1fr))` based on available grid width, not viewport-only column counts; at larger text sizes the minimum card width scales. Preserve all product selection, image processing, pricing and API behavior. Existing responsive contract remains for all roles; add photo-bearing catalog evidence across intermediate narrow-window sizes and 200% text; preserve actual image aspect ratios. CI fixtures contain no actual merchant photos. Real-domain owner acceptance remains pending.
